API Key

Key 和 Base URL 只会提交到后端。网页输入的 OpenAI Key 仅保存在当前服务进程内存，不写入浏览器存储，重启服务后会丢失。长期使用推荐在 `.env` 配置 OPENAI_API_KEY 和 OPENAI_BASE_URL。Base URL 可填写 OpenAI 兼容中转站地址，例如 https://api.openai.com/v1 或你的中转站 /v1 地址。
