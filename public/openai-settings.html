GPT5.5 文本视觉

GPT5.5 API 只用于读取图片、生成中文 prompt、款式英文名和 Etsy 商品文案，不参与最终图生图。网页输入的 GPT55_API_KEY 仅保存在当前服务进程内存，不写入浏览器存储、secure-config.json 或日志；重启服务后会丢失。长期使用推荐在 `.env` 配置 GPT55_API_KEY。

OpenAI 图生图

OpenAI Key 和 Base URL 只用于最终 Images edit 图生图。网页输入的 OpenAI Key 仅保存在当前服务进程内存，不写入浏览器存储，重启服务后会丢失。长期使用推荐在 `.env` 配置 OPENAI_API_KEY 和 OPENAI_BASE_URL。
